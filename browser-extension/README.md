# ARGON — Browser Extension (Manifest V3)

Lightning-fast download interception and context-menu accelerator for **ARGON**.

## Features
- **Auto-Interception**: Automatically catches browser downloads and accelerates them with ARGON's multi-part engine.
- **Context Menu**: Right-click any link, video, audio, or image to "Download with ARGON ⚡".
- **Local Loopback Bridge**: Communicates securely over local loopback (`http://127.0.0.1:41523`) with zero cloud overhead.
- **Offline Tolerance**: If ARGON is closed, downloads fall back transparently to native browser downloading.

## How to Install (Chrome, Edge, Brave, Opera)
1. Open your browser and navigate to `chrome://extensions` (or `edge://extensions`).
2. Toggle on **Developer mode** in the top right corner.
3. Click **Load unpacked** (تحميل حزمة غير مضغوطة).
4. Select this `browser-extension` folder.
5. ARGON is now integrated!
