# ARGON 2.5.1

- **Windows updater.** Fixed a lock conflict that could report an update was already running when clicking **Install and restart**. The native installer manages the lock and resumes queue processing if it cannot launch the installer.
- **Android launcher icon.** The ARGON mark is larger and clearer at small sizes. The updated icon includes adaptive, round and monochrome versions.

If an older Windows installation shows the update-busy error, finish any transfers, quit ARGON from the notification area and run the Windows x64 installer from this release once. It upgrades the existing installation in place.
