# ARGON 2.7.7

- **High-Performance In-Memory Social TTL Cache:** Eliminates redundant network queries between media format discovery and actual download execution. Media streams now start instantly (0ms resolution latency) on duplicate checks and retries.
- **Enhanced Facebook Zero-Login Extractor:** Integrated Facebook's embed plugin endpoint (`plugins/video.php`) as Layer 1, completely bypassing login walls for public videos, reels, and watch clips. Full fallbacks to desktop/mobile scraping and photo extraction remain active.
- **Dedicated Extractors for Threads, Streamable & Snapchat:**
  - Added dedicated pure-Rust parsing for **Threads** (`threads.net`) posts, extracting HD/SD video streams and photo attachments.
  - Added native API integration for **Streamable** (`api.streamable.com/videos/`), pulling direct HD/SD MP4 URLs, exact bitrates, and dimensions in milliseconds.
  - Added dedicated scraper for **Snapchat Spotlight** clips with automatic fallback to generic HTML og-video parser.
- **Social Media Fast-Pathing on Desktop:** Streamlined `list_media_formats` to prioritize high-speed pure-Rust extraction for social platforms (Instagram, TikTok, Twitter/X, Facebook, Threads, Pinterest, Snapchat, Streamable), resolving media in under 500ms without waiting for heavy external tool subprocesses.
- **QuickAddBar Responsiveness & Early-Click Safeguard:**
  - Reduced media probing debounce from 450ms to 200ms for snappier UI feedback.
  - Added early-submit fallback preserving detected platform metadata so rapid Enter/Click actions before probing finishes seamlessly resolve on download start.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.7.7_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.7.7-portable.zip**.
- **Android arm64:** Install **ARGON_2.7.7_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.7.7-browser-extension.zip**.
