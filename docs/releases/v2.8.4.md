# ARGON 2.8.4

- **Interactive Android Foreground Service & Live Notifications:**
  - Added interactive notification controls to `DownloadForegroundService` on Android, featuring a direct **Pause All / إيقاف مؤقت للكل** action button (`PendingIntent`).
  - Broadcasts notification events back into the active instance and download manager, allowing one-tap management without opening the app.
- **Deep Android Intent Filters & Media Handlers:**
  - Added native intent filters in `AndroidManifest.xml` capturing `magnet:` URIs, torrent files (`application/x-bittorrent`), and `.torrent` extensions across browser downloads and file pickers.
  - Added multi-file intent handling (`ACTION_SEND_MULTIPLE`) to intake shared files directly into ARGON Flow sharing from any Android application.
- **Native MediaStore Auto-Indexing on Android:**
  - Integrated `MediaScannerConnection` automated indexing via the new `scan_media_file` Rust and Kotlin bridge.
  - Automatically notifies the Android media provider upon task completion, ensuring downloaded videos, music, and images appear immediately in the system Gallery and media players.
- **Battery Optimization Exemption Shortcut:**
  - Added native battery optimization check and exemption request (`ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`) under General Settings.
  - Prevents aggressive OEM background app killers from halting multi-segment transfers during lock screen or low-power states.
- **Browser Extension Overhaul & Magnet Bridge:**
  - Upgraded the ARGON browser extension popup to the Obsidian Titanium design language with enhanced responsive contrast and RTL typography.
  - Added direct magnet link intake and dispatch from the browser extension popup to the ARGON desktop bridge.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.8.4_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.8.4-portable.zip**.
- **Android arm64:** Install **ARGON_2.8.4_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.8.4-browser-extension.zip**.
