# ARGON 2.8.2

- **P2P Flow Transfer Resilience & Android Background Service:**
  - Resolved stalled transfers between Android and desktop devices by integrating `DownloadForegroundService` with local file sharing in `flowClient.ts`.
  - Flow transfers on Android now actively hold `PARTIAL_WAKE_LOCK` and `WIFI_MODE_FULL_HIGH_PERF`, preventing background sleep and OS socket freezes.
  - Configured aggressive TCP Keepalive (5s idle, 2s interval, 3 probes) in `flow-core/src/wire.rs` to detect network drops promptly.
  - Added `flow_retry_transfer` native command and 1-click retry button (`RotateCcw`) in `FlowPanels.tsx` to instantly resume interrupted or timed-out transfers.
- **Hardened Browser Bridge Security:**
  - Added dynamic session-scoped cryptographic Bearer token authentication to the local browser bridge on port 41523.
  - Strictly restricted `/add` and `/handoff/*` endpoints to verified browser extension origins and valid bearer tokens, eliminating unauthorized local access.
  - Updated browser extension client to perform automated handshake and attach credentials to every transfer handoff.
- **Real-Debrid Magnet & Torrent Download Support:**
  - Unblocked `magnet:` links in `downloadManager.ts` and `downloader-core/src/service.rs` when Real-Debrid unrestriction is configured.
  - Magnets and torrents now resolve automatically into high-speed multi-segment downloads via Real-Debrid.
  - Provided clear diagnostic messages directing users to configure their Real-Debrid API token if attempting torrent downloads without it.
- **Performance & Scheduler Improvements:**
  - Converted Flow background snapshot polling to event-driven execution, completely eliminating idle CPU cycles when no transfers are active.
  - Updated `TaskCard` queue status to explicitly display "بانتظار الجدول الليلي" for tasks deferred by the night scheduler.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.8.2_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.8.2-portable.zip**.
- **Android arm64:** Install **ARGON_2.8.2_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.8.2-browser-extension.zip**.
