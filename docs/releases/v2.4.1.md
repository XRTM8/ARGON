# ARGON 2.4.1

- **Native Android Clipboard Bridge (`ClipboardManager`):** Fixed mobile clipboard paste failures where mobile WebViews prompted users to press desktop "Ctrl+V". Routed clipboard intake directly to Android's native `ClipboardManager` via `flow_read_clipboard` and `flow_write_clipboard` running on `runOnUiThread`, eliminating web permission blocks and allowing instantaneous link pasting from any application.
- **Android FileProvider & Media Viewing Resolution:** Resolved `IllegalArgumentException: Failed to find configured root` when opening downloaded videos and media on Android. Updated `file_paths.xml` with `<root-path name="root" path="." />` and `<files-path name="data_root" path="../" />`, ensured broad storage directory coverage across `Movies`, `Pictures`, and `Downloads`, and granted explicit URI read permissions with automatic MIME type fallback (`*/*`).
- **Mobile Ergonomics & Status Bar Safe-Area Insets:** Elevated top safe-area floor to 40px to prevent the status bar (clock, battery, Wi-Fi) and punch-hole camera cutouts from overlapping top navigation and actions.
- **Humanized Error Handling & Typography:** Replaced raw English Java stack traces on download cards with styled, humanized Arabic/English alert banners featuring dedicated icons and dismiss buttons (`[X]`).
- **Quick-Add Interface Polish:** Removed vertical resize grips and unnecessary scrollbar artifacts from the URL input textarea on mobile touchscreens, and turned confirmation notices into neat self-dismissing badges.
- **Direct Inline Sharing:** Added a quick Share button (`Share2`) alongside Open (`ExternalLink`) for completed downloads on Android to streamline dispatching videos directly to messaging and social apps.

## Install & Upgrade Without Package Conflicts

- **Windows x64 Installer:** Run **ARGON_2.4.1_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS). Existing signed installations upgrade seamlessly in place.
- **Windows x64 Portable:** Extract **argon-2.4.1-portable.zip** cleanly alongside `tools/` and `browser-extension/`.
- **Android arm64:** Install **ARGON_2.4.1_arm64.apk** (`com.otium.downloader`). Maintains identical application ID and monotonic `versionCode` (2040100) ensuring error-free upgrades without package conflicts (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`).
- **Browser Extension:** Unpack **argon-2.4.1-browser-extension.zip** in Chrome/Edge (`manifest.json`) or load `manifest.firefox.json` in Firefox.
