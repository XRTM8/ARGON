# ARGON 2.8.0

- **Queue Priority & Manual Reordering Engine:**
  - Added `queue_priority` to tasks, replacing strict FIFO queuing with a priority-aware scheduler in `downloader-core`. High-priority tasks execute ahead of older queued tasks automatically.
  - Added native commands `dl_set_task_priority` and `dl_bump_task_queue` to move any queued download straight to the top or bottom of the queue.
  - Added interactive quick-reorder buttons (`↑` Move to top / `↓` Move to bottom) and visual priority badges in `TaskCard`.
  - Updated `TaskList` sorting to mirror the backend scheduler: queued items sort by priority descending, then creation timestamp.
- **Post-Download Power Actions (Sleep & Hibernate):**
  - Expanded post-completion behavior beyond hard system shutdown (`shutdown /s`).
  - Added native Windows power action triggers: **Sleep** via `rundll32.exe powrprof.dll,SetSuspendState 0,1,0` to preserve running applications and unsaved sessions, and **Hibernate** via `shutdown /h`.
  - Added dedicated selector in Settings under completion actions, letting users configure their preferred power state with zero hassle.
- **Reliability & Scheduler Refinements:**
  - Hardened auto-shutdown and sleep triggers to read user preferences directly on `AllIdleShutdownPending`.
  - Ensured seamless persistence of task priorities across restarts and settings updates.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.8.0_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.8.0-portable.zip**.
- **Android arm64:** Install **ARGON_2.8.0_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.8.0-browser-extension.zip**.
