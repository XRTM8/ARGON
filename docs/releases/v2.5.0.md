# ARGON 2.5.0

- **Safer download resume.** ARGON checks the effective URL, file size and strong ETag before reusing partial data. It restarts from byte zero if the file changed or the saved data cannot be verified. Servers without a strong ETag use a single connection.
- **Recoverable browser handoff.** The extension and desktop app use one request ID to recover from a lost reply. ARGON saves the task, then starts it when the extension confirms the handoff. The Browser extension page includes a test download.
- **Send finished downloads to a paired device.** Choose an online device from the download row and follow the transfer in place. Pairing by QR uses a two-minute invitation and still asks for confirmation on both devices.
- **HLS and DASH on desktop.** With FFmpeg installed, ARGON can download unprotected streams, merge audio and video, and show when it is merging. The final file is saved under a unique name after processing completes.

## Downloads

Use the Windows x64 installer to upgrade an existing installation. Portable users can extract the ZIP into a separate directory. The Android APK is built for arm64. Update the browser extension from its ZIP to use the new handoff protocol.
