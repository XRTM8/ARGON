# ARGON 2.8.3

- **IPv4 Multicast Peer Discovery in Flow (Local Sharing):**
  - Integrated administrative local multicast group discovery (`239.255.54.126`) alongside standard UDP broadcast (`255.255.255.255` and subnet broadcasts) in `flow-core`.
  - Enables seamless auto-discovery between desktop and mobile devices even on Wi-Fi routers with active Access Point (AP) / Client Isolation or broadcast suppression.
- **In-Progress Media Streaming & Preview:**
  - Added real-time media preview action (`Eye` icon) in `TaskCard` for video and audio downloads once the first 2 MB of initial keyframes and headers are buffered.
  - Allows opening partial media files in default system media players (VLC, Windows Media Player, mpv) to watch or listen while ARGON continues parallel multi-segment downloading in the background.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.8.3_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.8.3-portable.zip**.
- **Android arm64:** Install **ARGON_2.8.3_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.8.3-browser-extension.zip**.
