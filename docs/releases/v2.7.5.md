# ARGON 2.7.5

- **Android Automatic Updates Activation:** Fixed the automatic updates toggle switch on Android. Users can now enable background update checks (at startup and every 6 hours); when a new release is available, the verified arm64 APK is automatically queued and downloaded with SHA-256 verification.
- **Native Toggle Switch Upgrade:** Replaced the unstyled HTML checkbox with ARGON's animated, accessible `argon-switch` component, delivering tactile haptic-ready sliding feedback and full RTL alignment.
- **Background Release Sync:** Ensured update preferences persist across Android app restarts and gracefully coordinate with background network state.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.7.5_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.7.5-portable.zip**.
- **Android arm64:** Install **ARGON_2.7.5_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.7.5-browser-extension.zip**.
