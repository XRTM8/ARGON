# ARGON 2.4.0

- **Pure-Rust Download Core (`downloader-core`):** Migrated task scheduling, per-host concurrency limits, atomic `MoveFileExW` persistence, exponential auto-retry, mirror fallback, dynamic work-stealing, POST + Cookie forwarding, and stall-decay telemetry completely into native Rust so desktop captures and background queues run independently of frontend lifecycles.
- **Native Social Media Downloads on Android & Windows:** Added pure-Rust extraction (`downloader-core::social`) supporting YouTube (`ANDROID_VR`/`ANDROID` muxed MP4 + adaptive), Instagram Reels/Posts, TikTok (watermark-free HD), X/Twitter, Facebook, Reddit, Vimeo, and Threads directly on Android and desktop, plus automatic HD muxing (`yt-dlp` + on-demand SHA-256-verified `FFmpeg` setup) on Windows.
- **Android Public Storage & MediaStore Publishing:** Fixed Android download paths and `FileProvider` compatibility, and added automatic `MediaStore` export so completed videos appear immediately in Gallery (`Movies/ARGON`) and files appear directly in `Downloads/ARGON`.
- **Browser Integration & System Tray Upgrades:** Added Firefox Manifest V3 (`manifest.firefox.json`), optional non-incognito cookie forwarding, HLS/DASH `ffmpeg-hls` capability gating, Windows System Tray minimize-on-close, and `--minimized` Windows startup support.
- **Unified Simplified UI/UX Overhaul:** Streamlined navigation to 4 unified destinations across desktop and mobile, eliminated redundant overview cards and nested clutter, fixed Arabic RTL byte/speed formatting (`dir="ltr"`), and moved task controls cleanly inline.

## Install & Upgrade Without Package Conflicts

- **Windows x64 Installer:** Run **ARGON_2.4.0_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS). Existing signed installations upgrade in place via **Settings -> Updates**.
- **Windows x64 Portable:** Extract **argon-2.4.0-portable.zip** cleanly while keeping `tools/` and `browser-extension/` alongside `ARGON.exe`.
- **Android arm64:** Install **ARGON_2.4.0_arm64.apk** (`com.otium.downloader`). Signed releases preserve the persistent Android certificate and monotonic `versionCode` for seamless upgrades.
- **Browser Extension:** Unpack **argon-2.4.0-browser-extension.zip** in Chrome/Edge (`manifest.json`) or load `manifest.firefox.json` in Firefox.
