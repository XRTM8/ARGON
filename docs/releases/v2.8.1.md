# ARGON 2.8.1

- **Fix Media Stream Download Failure (HTTP 403 Forbidden):**
  - Resolved access denied / 403 errors when downloading YouTube and other platform streams caused by strict CDN requirements.
  - Adjusted range execution in `downloader-core/src/service.rs` to allow ranged parallel transfers when `Last-Modified` or media context is present, even in the absence of an ETag header.
  - Enhanced `transfer.rs` single-stream fallback to supply `Range: bytes=0-` for sized GET requests and gracefully handle `206 Partial Content` responses, preventing streaming edge servers from aborting connections.
  - Sanitized YouTube format extractor in `downloader-core/src/social.rs` to prioritize direct endpoints, eliminate ciphered links without active signatures, and provide accurate `User-Agent` headers.
- **Revamped Media Format Selector UI:**
  - Redesigned format selection in `QuickAddBar` with clean segmented tabs dividing **Video** and **Audio** streams with format counters and dedicated iconography.
  - Automated detection and ranking of the highest quality stream in each category, highlighting it with an animated **★ الأفضل / Best** gold badge.
  - Automated selection of the best available format upon probe completion.
  - Enhanced audio formats with exact bitrate indicators (e.g. `128 kbps`, `160 kbps`, `48 kbps`) and container badges (`MP4`, `M4A`, `WEBM`) to eliminate ambiguous duplicate labels.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.8.1_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.8.1-portable.zip**.
- **Android arm64:** Install **ARGON_2.8.1_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.8.1-browser-extension.zip**.
