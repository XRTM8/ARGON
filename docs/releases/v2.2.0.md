# ARGON 2.2.0

- Compact browser extension: fixed-width popup, automatic page-file discovery and a download action beside each result. Advanced options stay collapsed.
- Optional video download button over supported media. Known social-video pages use ARGON's desktop extractor; isolated stream fragments are filtered out. DRM and arbitrary HLS/DASH streams remain unsupported.
- Optional automatic checking and downloading of signed Windows updates, off by default. Install explicitly after active downloads and sharing finish. Signatures bind the package to its version.
- Package-aware updates: the installed app upgrades its existing per-user installation; Portable copies download the corresponding ZIP. Single-instance handling and transfer guards reduce update conflicts.

## Install

For Windows x64, use **ARGON_2.2.0_x64-setup.exe**, or extract the complete **argon-2.2.0-portable.zip** into a separate folder. Keep `tools/` and `browser-extension/` beside the portable executable.

For Brave, Chrome or Edge, extract **argon-2.2.0-browser-extension.zip**, then select its folder with **Load unpacked** in the browser's extension manager. Reload an existing extension after replacing its files, and reload open video pages. ARGON must be running to receive downloads; discovery itself can work while it is closed.

Upgrading from 2.1.0 requires installing 2.2.0 once manually. To opt into future update checks and downloads, open **Settings → Application updates**. Installation remains under your control.

Tests cover update opt-in, package matching, duplicate-operation prevention, queue protection, cached-package validation, browser handoff recovery and video-target selection. A simulated browser fixture checks popup layout; it does not replace testing a real installed browser extension or a future-version Windows upgrade.
