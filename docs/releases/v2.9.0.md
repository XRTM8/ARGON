# ARGON 2.9.0

- **Browser Bridge Security & Real Native Messaging Wake Host:**
  - Removed unauthenticated `token` disclosure from `GET /ping` and `GET /status` and removed the `Origin: chrome-extension://*` authentication bypass on `POST /add` and `POST /handoff/*`; all download and handoff requests now require a persisted, constant-time-verified Bridge Key.
  - Added a Bridge Key pairing view in **Browser Integration** (copy & rotate) and pairing input in the browser extension popup (`bridge-client.js`, `popup.html`, `popup.js`).
  - Implemented the actual stdio Native Messaging wake handler in `src-tauri/src/main.rs` and removed the invalid `"chrome-extension://*/"` wildcard from the Windows registry manifest.
- **Zero-Contention Runtime & Lightweight Telemetry IPC:**
  - Replaced `DownloaderRuntime`'s global `tokio::sync::Mutex` with lock-free `tokio::sync::OnceCell` initialization so 30 Hz binary telemetry polling and IPC commands do not contend.
  - Added `DownloadEvent::TelemetryTick` so periodic speed/stats updates no longer trigger full-task-list JSON `dl_snapshot` serialization every 500 ms.
- **Core Service & Frontend Modularization:**
  - Decomposed `downloader-core/src/service.rs` (3,258 lines) into focused `service/{mod.rs, handoff.rs, queue.rs, executor.rs, tests.rs}` submodules.
  - Modularized `src/argon.css` (2,648 lines) into `src/styles/{tokens.css, layout.css, downloads.css, views.css, mobile.css}`, defined missing theme variables, and eliminated hardcoded dark inline styles breaking Light Mode.
  - Extracted `CookieModal`, `HistoryView`, and `MiniWidget` from oversized components, removed duplicate download toolbars in `App.tsx`, and synced `SettingsView` reactively with `downloadManager`.
- **Platform & UI Honesty Fixes:**
  - Aligned `startWithWindows` default to `false` across Rust and TypeScript and synced the Windows startup registry entry during app setup.
  - Clarified platform-specific behavior for media sniffer actions (in-app WebView sniffer on Android vs external paired browser on desktop) and Real-Debrid requirement for `.torrent` / Magnet links.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.9.0_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.9.0-portable.zip**.
- **Android arm64:** Install **ARGON_2.9.0_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.9.0-browser-extension.zip**.
