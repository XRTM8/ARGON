# ARGON 2.4.2

- **In-Place Seamless In-App Updates Without Uninstallation:** Eliminated the forced uninstallation routine during application updates. Custom NSIS template (`nsis/installer.nsi`) now skips the reinstall/uninstall maintenance prompt entirely when invoked in passive or update mode (`/UPDATE /P`), defaulting to in-place file overwrites while strictly preserving all user downloads, settings, and registry entries.
- **NSIS Binary Lock Release Polling (`binary_lock_wait`):** Added a dedicated 5-second polling loop in the installer that waits for previous `ARGON.exe` process handles to cleanly release before overwriting executables, eliminating `ERROR_SHARING_VIOLATION` during background updates.
- **Resilient Installation Mode Detection:** Decoupled `package_mode()` in `src-tauri/src/updater.rs` from `uninstall.exe` file presence. The engine now recognizes installed instances by validating active execution paths against registered `InstallLocation` registry keys, preventing accidental fallbacks to portable mode.
- **Browser Native Messaging & Silent Interception:** Added Native Messaging host integration (`com.otium.downloader`) allowing browser extensions to automatically launch ARGON when closed upon link capture, and hooked Chromium `onDeterminingFilename` to suppress native browser "Save As" location dialogs.
- **Automated Night Scheduler Engine:** Integrated an autonomous ticker in `downloader-core/src/service.rs` that automatically wakes queued transfers when entering the scheduled night window and safely pauses transfers when the window elapses (respecting force-started tasks).
- **Intelligent Category Auto-Routing:** Configured automatic categorization of downloaded files into dedicated directories (`Programs`, `Videos`, `Documents`, `Compressed`, `Music`) with dynamic directory creation.
- **Fail-Fast Disk Write Error Propagation:** Enhanced `CoalescedDiskWriter` with shared thread-safe error tracking, immediately halting downloads and surfacing clear error states when disk space is exhausted rather than silently losing buffered data.
- **Self-Healing yt-dlp Toolchain:** Added automatic tool updating and extraction retry in `src-tauri/src/media.rs` whenever media parsing encounters extractor errors.
- **Desktop Clipboard Link Monitor:** Implemented background polling of the system clipboard via `arboard`, automatically broadcasting detected download URLs to the application UI.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.4.2_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS). Existing installations upgrade cleanly in-place without uninstallation.
- **Windows x64 Portable:** Extract **argon-2.4.2-portable.zip** alongside `tools/` and `browser-extension/`.
- **Android arm64:** Install **ARGON_2.4.2_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.4.2-browser-extension.zip** in Chrome, Edge, or Brave (`manifest.json`), or `manifest.firefox.json` in Firefox.
