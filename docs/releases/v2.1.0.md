# ARGON 2.1.0

This release improves download management and browser integration.

- A quieter Arabic/English interface with readable file rows and phone navigation.
- Review multiple links before adding them, with exact duplicate detection, search, status/type filters, sorting and selection actions.
- Replace expired download links. Partial data is reused only after resource and server-validator checks; old authentication headers are cleared.
- Chrome/Edge extension with Arabic/English controls, selected page-file downloads, transient media discovery, website exclusions and minimum capture sizes.
- Automatic browser capture is opt-in. A browser download is cancelled only after ARGON confirms saving the task. Failed handoffs resume it.
- Correct distinctions between calculating SHA-256 and matching a reference hash; disk deletion failures remain visible.
- The portable ZIP contains ARGON.exe, the media tools and the browser extension. Extract the entire ZIP before running it.

## Downloads

- `ARGON_2.1.0_x64-setup.exe`: Windows x64 installer, including media tools and browser integration.
- `argon-2.1.0-portable.zip`: complete Windows x64 portable folder.
- `argon-2.1.0-browser-extension.zip`: Chrome/Edge extension. Extract it, enable Developer mode in your browser's extension manager, and choose Load unpacked. Open ARGON's Browser extension section for setup.
- `SHA256SUMS.txt`: SHA-256 checksums for the downloadable assets.

Update the desktop app and extension together. An older desktop build does not support the new saved-task acknowledgement protocol.

## Current limits

Direct HTTP/HTTPS downloads and supported platform links are available. HLS/DASH playlists, blob/DRM streams, torrent transfers and Firefox integration are not supported. Browser cookies and POST bodies are not copied, so some authenticated links require a fresh direct URL. Keep ARGON open during transfers. This release does not contain a new Android APK.

No controlled throughput comparison with IDM was performed. Build and automated test results are available in the linked GitHub Actions runs; they do not replace manual browser integration testing.
