# ARGON 2.7.0

- **BitTorrent Intake Overhaul & Native Drag-and-Drop:** Full drag-and-drop intake for `.torrent` files and BitTorrent magnet URIs directly onto the application window and QuickAddBar console. Added a dedicated local `.torrent` file picker button that parses bencoded payload metadata (infoHash, total size, file count) client-side into interactive visual badges.
- **Category Filter Parity & Torrent Badges:** Added the missing `torrents` category option to the task filter dropdown in `TaskList`, completing parity with the backend `TaskCategory` model. `TaskCard` now displays prominent Torrent badges with a clean `TOR` tile, and `TaskInspector` exposes detailed BitTorrent metadata (BTIH hash, total files, and payload volume).
- **Adaptive Connection Scaling Engine:** Implemented `recommended_segment_count` across Rust (`argon-downloader-core`) and TypeScript (`src/core/segmentation.ts`). Intelligently adjusts connection concurrency based on payload size: avoids TLS/TCP handshake and fragmentation overhead on small files (< 1MB -> single stream) while dynamically scaling up to 16–32 connections on large multi-gigabyte transfers.
- **Desktop-Fidelity Android Adaptive Icon:** Re-engineered the Android launcher icon pipeline with matching obsidian gradient (`#161D2A` to `#090C11`), Arctic White prism 'A', cobalt blue gradient vector (`#60A5FA` to `#2563EB`), and drop shadow scaled to Android's 66dp–72dp safe zone across all mipmap densities (`hdpi`, `mdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`) plus Material You monochrome support.
- **CI/CD Concurrency & Idempotent Release Pipeline:** Unified GitHub Actions concurrency to `release-pipeline` and introduced idempotent release detection to eliminate race conditions between branch and tag triggers.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.7.0_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS). Existing installations upgrade cleanly in-place.
- **Windows x64 Portable:** Extract **argon-2.7.0-portable.zip** alongside `tools/` and `browser-extension/`.
- **Android arm64:** Install **ARGON_2.7.0_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.7.0-browser-extension.zip** in Chrome, Edge, or Brave (`manifest.json`), or `manifest.firefox.json` in Firefox.
