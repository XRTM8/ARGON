# ARGON 2.10.2

- **Release Packaging & Visual Identity Maintenance:**
  - Maintenance release bundling the Luxury AMOLED Black & Pure AMOLED White dual-polarity visual identity, the Obsidian Crimson Prism multi-platform icon suite, and Browser Extension AMOLED White support on a clean tagged build.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.10.2_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.10.2-portable.zip**.
- **Android arm64:** Install **ARGON_2.10.2_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.10.2-browser-extension.zip**.
