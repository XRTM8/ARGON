# ARGON 2.7.3

- **HTTP/2 Multiplexing:** Upgraded network transport engine with native HTTP/2 stream multiplexing, HPACK binary header compression, and connection re-use across multi-segment downloads and CDNs.
- **Desktop Mini Mode & Floating Glass Dock:** Added a dedicated compact desktop monitoring mode (`Minimize2` / `Maximize2`). Collapses the main window into an ultra-compact floating widget with real-time throughput sparkline, active task progress track, quick play/pause controls, and instant restoration.
- **Auto Media Probe on Paste:** Links pasted into the download input are automatically probed via debounced inspection (450ms) to immediately extract video thumbnail, channel name, duration, and quality chips without requiring manual clicks.
- **Virtual Layout Containment (120 FPS List Scrolling):** Applied CSS `content-visibility: auto` and strict paint/layout containment to download task cards, isolating offscreen DOM reflows and guaranteeing silky-smooth 120 FPS scrolling even with hundreds of completed items.
- **One-Click SHA-256 Hash Verification:** Converted raw hash display in task cards into an interactive, 1-click clipboard copy button with instant checkmark feedback and integrity indicator.
- **Official Store Publishing Package & Privacy Docs:** Created formal open-source privacy policy (`docs/PRIVACY.md`) and Chrome Web Store / Microsoft Edge Add-ons store submission manifest (`browser-extension/STORE_LISTING.md`) with explicit single-purpose justifications and permission rationales.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.7.3_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.7.3-portable.zip**.
- **Android arm64:** Install **ARGON_2.7.3_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.7.3-browser-extension.zip**.
