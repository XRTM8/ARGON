# ARGON v3.1.0

## Highlights
- **Windows NTFS Sparse Files (`FSCTL_SET_SPARSE`)**: Prevents synchronous NTFS zero-fill stalls during out-of-order segment writes and pause/resume on large files.
- **Engine Memory Budget (`Semaphore`)**: Bounds in-flight write buffers to 64 MiB with TCP backpressure on slow disks.
- **Adaptive Per-Host Connection Limits (`HostLimits`)**: Automatically detects `429`/`503`/`403` connection refusals and lowers per-host concurrency with a 30-minute TTL.
- **Local BitTorrent / Magnet Support (`librqbit`)**: Desktop builds now download `magnet:` links natively without requiring Real-Debrid.
- **Remote ZIP Peek & Single-File Extraction**: Inspect remote `.zip` archives via HTTP Range requests and extract individual files (with 128 MiB safety & ZIP-bomb bounds).
- **Hugging Face Model Downloader**: Fetch model/dataset repositories, filter `GGUF` quantizations, verify LFS `SHA-256`, and support `hf-mirror.com`.
- **Post-Download Antivirus Scan**: Optional automatic scanning via Windows Defender (`MpCmdRun.exe`) or `clamscan`.
- **Network Proxy & Category Save Folders**: Configurable `system` / `none` / `http` / `socks5` proxy and per-category destination folders.
- **Pure-Rust WAL Persistence & Multi-Browser Repair**: Incremental `tasks.wal` journal with atomic `tasks.json` compaction, plus one-click Native Messaging repair for Chrome, Edge, Chromium, Brave, Vivaldi, and Firefox.
