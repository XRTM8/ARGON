# ARGON 2.3.0

- **Corporate Slate UI & Vector Brand Identity:** Rebuilt desktop and mobile interface with High-Contrast Slate Dark and Crisp Porcelain Light modes, unified header/navigation ergonomics, Quick-Add intake bar (Direct, Batch, Wildcard patterns), live segment inspector, and `Ctrl+K` command palette.
- **Full Mobile Edge-to-Edge Safe-Area & Android Background Service:** Native Android `WindowInsetsCompat` telemetry prevents UI overlap beneath system status/navigation bars and soft keyboards, paired with a persistent dataSync foreground service notification and direct Share Sheet intake.
- **Zero-GC Binary Telemetry & Coalesced Disk I/O:** Dedicated Rust disk writer thread (`CoalescedDiskWriter`) with buffer recycling, lock-free atomic GCRA pacing, zero-poll `watch` cancellation, 1 MiB buffered SHA-256 verification, and 30fps binary IPC (`ARG3`) updating GPU-composited progress bars without React allocation churn.
- **Reliable Cross-Platform In-App Updates:** Fixed GitHub release redirect CSP allowlist (`release-assets.githubusercontent.com`), GitHub REST `digest` checksum extraction, native Rust release feed fallback (`fetch_release_feed`), hardened Windows NSIS registry detection, clean exit handoff on install, Android `REQUEST_INSTALL_PACKAGES` installer launch, and unified desktop + signed arm64 Android APK CI release pipeline.

## Install & Upgrade Without Package Conflicts

- **Windows x64 Installer:** Run **ARGON_2.3.0_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS). Future signed releases upgrade seamlessly inside **Settings -> Updates & Flow**.
- **Windows x64 Portable:** Extract **argon-2.3.0-portable.zip** cleanly while keeping `tools/` and `browser-extension/` alongside `ARGON.exe`.
- **Android arm64:** Install **ARGON_2.3.0_arm64.apk** (`com.otium.downloader`). Signed releases share the persistent Android release certificate (`ANDROID_KEYSTORE_BASE64`) and monotonic `versionCode` so future in-app `.apk` upgrades install cleanly without signature conflicts.
- **Browser Extension:** Unpack **argon-2.3.0-browser-extension.zip** and reload in Chrome/Edge/Brave.
