# ARGON 2.10.0

- **Luxury AMOLED Studio Visual Identity:**
  - Adopted the Pure AMOLED Black (`#000000`) & Studio Dark (`#0A0B0E` / `#14151B` / `#1E2028`) + Pure AMOLED White (`#FFFFFF` / `#F6F7F9` / `#ECEEF2`) dual-polarity design system anchored by Velvet Burgundy (`#9E1B42` / `#72142B`) and crisp hairline borders.
  - Upgraded the Quick-Add Intake console, sidebar navigation, dialogs, progress bars, mobile bottom dock, and Browser Extension popup to unified CSS theme tokens with clean Light Mode contrast.
  - Replaced hardcoded inline accent colors in `TaskCard`, `QuickAddBar`, and `TaskInspector` with theme-aware CSS classes and added a subtle burgundy version pill in the sidebar brand lockup.
- **New Obsidian Crimson Prism Icon:**
  - Redesigned `ArgonMark`, `public/argon.svg`, `browser-extension/mark.svg`, desktop `.ico`/`.icns`/`.png`, and Android adaptive/monochrome launcher layers around the new Obsidian Crimson Prism emblem (`#070204` wine-black base, concentric burgundy halos, architectural platinum A-blades, platinum-rose diamond core, and velvet crimson download vector).
  - Updated Android native WebView and theme resources (`colors.xml`, `ic_launcher_background.xml`, `MainActivity.kt`) to `#000000` / `#FFFFFF` / `#9E1B42`.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.10.0_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.10.0-portable.zip**.
- **Android arm64:** Install **ARGON_2.10.0_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.10.0-browser-extension.zip**.
