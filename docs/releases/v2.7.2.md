# ARGON 2.7.2

- **Unified Smart Download Stream:** Replaced the split "In progress" and "Completed" tabs with a unified smart stream. Active, downloading, and paused tasks are pinned at the top with live progress and action controls, while completed downloads appear directly underneath in chronological order separated by an elegant divider. Eliminates the empty state void when completed files exist.
- **Pure Vector Brand Emblem:** Replaced the hollow border tile on light mode with the crisp, scalable pure vector emblem. Dynamically adapts via `currentColor` and `--argon-accent` to render deep obsidian graphite on light mode and arctic white on dark mode, with zero SVG renderer bugs or gradient ID collisions.
- **Bidi Arabic Typography Fix:** Corrected inverted punctuation in the download input placeholder to read clean and straight: "أدخل رابط التحميل أو أسقط ملفاً", with automatic directional switching to LTR upon pasting URLs.
- **Executive Empty State & Neutral Disabled Controls:** Replaced the desktop dashed dropzone box with an elegant, compact card featuring a soft circular accent badge and clear guidance. Styled disabled primary buttons with clean, neutral surface backgrounds across both dark and light modes.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.7.2_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.7.2-portable.zip**.
- **Android arm64:** Install **ARGON_2.7.2_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.7.2-browser-extension.zip**.
