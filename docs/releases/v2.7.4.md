# ARGON 2.7.4

- **Universal Instagram & Reels Engine Overhaul:** Resolved "Link corrupted or private account" errors caused by Meta API deprecations. Added native parsing for `ig.me` shortlinks, all Instagram URL structures (`/reel/`, `/reels/`, `/p/`, `/tv/`, `/share/reel/`, `/stories/`), multi-endpoint embed/graphql scraping, and full support for photo carousels (`.jpg` formats) instead of failing on image posts.
- **TikTok Shortlink & Photo Slideshow Support:** Resolved redirect chains for `vt.tiktok.com`, `vm.tiktok.com`, and `/t/` links into canonical numeric video IDs. Added complete support for TikTok photo slideshows (`data.images`) and audio tracks (`music`), downloading image sequences losslessly.
- **Account Cookies Manager (`cookies.txt` & `sessionid`):** Added a dedicated interactive Cookies Manager in Settings -> Downloads -> Media Engine. Paste full Netscape cookies or paste raw Instagram `sessionid` tokens directly; ARGON automatically formats, verifies, and saves them to bypass private account barriers.
- **Desktop In-App Media Sniffer & Instant Recovery:** Activated the Live Media Sniffer UI on desktop with quick shortcuts for Instagram, TikTok, and YouTube. When a private or restricted account error occurs, an instant action button appears in the download bar to launch the sniffer and capture direct streams with one click.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.7.4_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.7.4-portable.zip**.
- **Android arm64:** Install **ARGON_2.7.4_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.7.4-browser-extension.zip**.
