# ARGON 2.7.1

- **Arabic Brand Identity & Emblem Overhaul:** Corrected the top brand header in Arabic mode to display **آرغون** with native typography and proper RTL directionality. Upgraded the emblem mark to render inside the official rounded squircle tile with obsidian gradient, dark slate border, Arctic White prism, and cobalt arrow.
- **Deep Obsidian OLED & Executive Light Palette:** Transformed dark mode from murky dark blue to deep obsidian OLED black (`#07090E`), elevated card surfaces (`#0E121B`), and crisp micro-borders (`rgba(255, 255, 255, 0.08)`). Revamped primary action buttons with an Electric Cobalt gradient (`#3B82F6` to `#2563EB`) and subtle glow shadow.
- **Streamlined Mobile UI & Text Reduction:** Shortened the intake prompt to a clean single line ("أدخل الرابط أو أسقط ملفاً…"). Eliminated redundant mobile headers and duplicate file sizes on completed downloads (`9.56 MB` instead of `9.56 MB / 9.56 MB`).
- **Native Bottom Navigation Refinement:** Removed harsh rectangular border strokes from the active tab on mobile, replacing them with a sleek rounded pill highlight matching native iOS / Material You design patterns.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.7.1_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.7.1-portable.zip**.
- **Android arm64:** Install **ARGON_2.7.1_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.7.1-browser-extension.zip**.
