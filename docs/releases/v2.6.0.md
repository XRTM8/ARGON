# ARGON 2.6.0

- **Universal Social Media & Video Extractor Engine:** Integrated native Rust scrapers for 10+ social platforms (TikTok via TikWM, X/Twitter via FxTwitter, Instagram via embed HTML5 data, YouTube via InnerTube, Facebook, Reddit, Pinterest, Twitch, Kick, Bilibili, Bluesky) with smart direct fallback and auto-muxing via yt-dlp & FFmpeg.
- **Real-Debrid Multi-Host Unrestriction:** Added full premium hoster unrestrict capabilities supporting 50+ file hosters (Rapidgator, 1Fichier, Mega, Turbobit, etc.) and cached BitTorrent links directly through Real-Debrid API v1.0.
- **Native BitTorrent & Magnet Parser:** Implemented RFC 3174 compliant SHA-1 hashing, bencode decoder, and magnet URI parser (`urn:btih:`) extracting torrent name, piece layout, file list, and tracker lists.
- **Native Messaging Host Integration:** Windows registry registration (`com.otium.downloader`) for Chromium & Edge allowing the browser extension to trigger ARGON silently or launch it on capture.
- **Enhanced Browser Extension:** Upgraded video floating grab button with HTML5 `<video><source>` child fallback, silent interception, expanded media extensions (`opus`, `avif`, `m4a`, `m4v`, `flv`, `wmv`, `3gp`), and cookie-guarded handoff.
- **Windows In-Place Updater Lock Fix:** Fixed lock conflict reporting update busy when clicking **Install and restart**. The native installer manages the lock cleanly and resumes queue processing if launch fails.
- **Android Media Sniffer & Foreground Service:** Android `DownloadForegroundService` with dynamic notifications and native WebView media sniffer integration for capturing streams directly on mobile devices.
- **Dynamic Segment Work-Stealing & Disk Pre-allocation:** Kernel pre-allocation via `SetFileInformationByHandle` / `posix_fallocate` and zero-corruption dynamic chunk splitting for slow transfers.

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.6.0_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS). Existing installations upgrade cleanly in-place without uninstallation.
- **Windows x64 Portable:** Extract **argon-2.6.0-portable.zip** alongside `tools/` and `browser-extension/`.
- **Android arm64:** Install **ARGON_2.6.0_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.6.0-browser-extension.zip** in Chrome, Edge, or Brave (`manifest.json`), or `manifest.firefox.json` in Firefox.
