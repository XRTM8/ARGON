# ARGON 2.10.1

- **Pure AMOLED White Light Theme Parity:**
  - Refined `data-theme="light"` to match the crisp Pure AMOLED White palette (`#FFFFFF` canvas, `#F6F7F9` surfaces, `#ECEEF2` elevated controls, `#DFE2E8` hover states, `#0F1014` ink, and `#72142B` Deep Royal Burgundy accent).
  - Replaced remaining dark-mode-only `box-shadow`, `inset` shadows, dark translucent fills, and pale error text (`#FCA5A5` / `#F87171`) across `layout.css`, `downloads.css`, and `views.css` with theme-aware CSS custom properties (`--argon-panel-shadow`, `--argon-control-bg`, `--argon-backdrop`, `--argon-danger-text`, `--argon-file-tile-bg`).
  - Added Pure AMOLED White theme support and a header theme toggle (`☀` / `☾`) to the Browser Extension popup (`popup.html`, `popup.css`, `popup.js`, `core.js`).

## Install & Upgrade

- **Windows x64 Installer:** Run **ARGON_2.10.1_x64-setup.exe** (`com.otium.downloader`, currentUser NSIS).
- **Windows x64 Portable:** Extract **argon-2.10.1-portable.zip**.
- **Android arm64:** Install **ARGON_2.10.1_arm64.apk** (`com.otium.downloader`).
- **Browser Extension:** Load **argon-2.10.1-browser-extension.zip**.
