# Isolation experiment

Protocol modules and the protocol integration tests are copied without behavioral changes from XRTM8/Flow commit 6dfab3e652dcaee20b27cf2b174a837c20cb6c39 (2026-11-07). The library entry point and package manifest are specific to this feasibility experiment. Slint, mobile_engine, clipboard adapters and the updater are intentionally excluded from this test harness. This is not an integration into ARGON and is not production-ready.

Source: https://github.com/XRTM8/Flow/tree/6dfab3e652dcaee20b27cf2b174a837c20cb6c39
